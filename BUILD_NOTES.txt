MICRO TOOLS FREE - BUILD NOTES
Version 0.2.0 - 2026-10-17

Seven tools in one public, MIT-licensed package
PromptDiff: text differences and optional whitespace normalization.
ConfigDiff: JSON differences, escaped paths and ignored subtrees.
JSONLDoctor: strict object-row audit and explicit filtered copies.
LogRedact: documented credential patterns and supplied literal secrets.
StreamUsageAudit: captured Chat Completions SSE usage and saved-record comparison.
RetryLens: explicit recorded HTTP attempt timing and retry-header comparisons.
BatchContractCheck: dated Batch envelope profiles and file consistency checks.

Implementation and boundaries
The three new diagnostics use standard-library parsing, date arithmetic and fixed
field checks. No requests, credentials, model execution, retry scheduling,
execution-control framework or remote service is included.
The Batch schemas are self-contained Draft 2020-12 documents bundled in the package.
Inputs are preserved. Existing outputs are never overwritten.
See README.md and docs/DIAGNOSTICS.md for input formats, limits and interpretation.
Examples and sample-output contain fictional data.

Retained local evidence
119 tests passed on Windows with Python 3.14.3, with no failures, errors or skips.
See verification/python-3.14-v0.2.0.json for names and log.
The expanded demo exercises all seven tools and has eleven aggregate checks.
The older 55-test results in verification describe the previous four-tool release.

CI and distribution
The workflow tests Ubuntu and Windows with Python 3.11, 3.13 and 3.14.
It also compares fixed Batch checks with a development-only JSON Schema validator,
installs the package and checks all seven commands outside the source checkout.
Current completed execution results are linked from README.md.
The runtime has no third-party dependencies. Package installation uses setuptools.
Python 3.11+ is required; no standalone executable installer is supplied.
Source-tree examples/demo and tests are distributed through the source download.
Schemas are included in the installed Python package.
MANIFEST.json lists the published files and SHA-256 hashes, excluding itself.
Hashes describe bytes; they are not independent signatures.

Evidence limits
Functional tests do not establish market demand, production suitability,
recording completeness, billing accuracy or live provider acceptance.
Log redaction is limited to documented patterns and cannot certify disclosure.
No private source or synced project reference files were included or modified.
